## 🔗 ALTERNATIF DEPLOY

### Vercel (Lebih Bagus)
1. Buat repo GitHub: https://github.com/new
   - Name: `ai-screen-recorder`
   - Public
2. Push code:
   ```bash
   cd ~/projects/ai-screen-recorder
   git init
   git add .
   git commit -m "Initial commit"
   ```
