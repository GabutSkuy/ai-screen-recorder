## 📦 Installation

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Install
```bash
git clone https://github.com/Azzzz/ai-screen-recorder.git
cd ai-screen-recorder
npm install
npm run dev
```

### Build for Production
```bash
npm run build
npm run start
```

## 🎬 Usage

1. **Open the app** - Launch from terminal or desktop shortcut
2. **Select region** - Choose full screen, window, or custom region
3. **Record** - Click record, do your thing
4. **Auto-edit** - AI automatically crops, zooms, and adds transitions
5. **Export** - Download as MP4 (720p, 1080p, or 4K)

---

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **Video Processing:** FFmpeg.wasm
- **State Management:** Zustand
- **AI Features:** OpenAI API / Local ML models
