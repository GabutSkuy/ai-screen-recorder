## ✅ Step 1: Create GitHub Repo (5 minutes)

### A. Go to GitHub
👉 https://github.com/new

### B. Create Repo
- **Repository name:** `ai-screen-recorder`
- **Description:** `AI-powered screen recording & video editing tool`
- **Visibility:** Public
- **Don't initialize:** ✅ Uncheck README, .gitignore, license
- Click **Create repository**

### C. Copy the URL
It will look like:
```
https://github.com/Azzzz/ai-screen-recorder.git
```

---

## ✅ Step 2: Push to GitHub (1 minute)

Open terminal and run:

```bash
cd ~/projects/ai-screen-recorder

# Initialize git
git init
git config user.email "ridhoefendi02@gmail.com"
git config user.name "Azzzz"

# Add all files
git add .

# Commit
git commit -m "Initial commit: AI Screen Recorder MVP with monetization"

# Add remote (replace with YOUR repo URL)
git remote add origin https://github.com/Azzzz/ai-screen-recorder.git

# Push
git push -u origin main
```

---

## ✅ Step 3: Deploy to Vercel (2 minutes)

### A. Go to Vercel
👉 https://vercel.com/new

### B. Import Project
1. Click **Import** on your `ai-screen-recorder` repo
2. Vercel will auto-detect it's a Vite/React project
3. Click **Deploy**

### C. Get Your URL
After 1-2 minutes, you'll get:
```
https://ai-screen-recorder.vercel.app
```

**DONE!** 🎉
